1高德 Key 配置 仅需一次

注册/创建 Key：console.amap.com → 创建应用 → 添加 Key → 服务平台选「Web端(JS API)」。个人认证免费，测距调用量完全够用。

2仓库与车辆参数

车辆参数决定限高/限重/限行规避，请按实际配送车型填写；口径默认对齐手机 App：分别按「速度优先 / 不走高速 / 避免收费」算 3 条，取距离最短一条，与你截图选 136km 的逻辑一致。

使用步骤 / 常见问题
  1. 注册高德开放平台（个人认证，免费）→ 控制台「应用管理」→ 创建新应用 → 添加 Key，服务平台选 Web端(JS API)，同时记下「安全密钥」。
  2. 把 Key 和安全密钥填到①，仓库地址点「解析仓库坐标」确认定位无误（错一个字都会偏，务必核对）。
  3. 粘贴或上传门店清单（门店名称,详细地址），地址越详细定位越准；只有店名就写 店名,商丘 自动按POI匹配。
  4. 点「开始批量测距」，完成后导出 Excel。失败行会标注原因，可修复地址后重跑（自动跳过已成功行）。
  5. 距离口径：高德货车引擎（与 App 货车导航同源），三条路线取最短，单位公里保留 1 位小数。
