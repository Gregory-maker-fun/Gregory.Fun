本地预览

  1. 直接双击 index.html 即可在浏览器查看。
  2. 或在本目录运行 python -m http.server 8000，访问 http://localhost:8000。

上线步骤（你本人操作）

  1. 注册 GitHub 账号，新建一个空仓库（如 my-site）。
  2. 将本目录 push 到该仓库（命令见 README）。
  3. 注册 Cloudflare 账号，进入 Pages → 连接 Git 仓库。
  4. 框架预设选「无」，构建命令留空，发布目录填 ./。
  5. 部署完成后获得 *.pages.dev 临时域名。
  6. 购买域名并将其 NS 改为 Cloudflare 提供的地址。
  7. 在 Cloudflare 添加自定义域名，SSL 选 Full，强制 HTTPS。
