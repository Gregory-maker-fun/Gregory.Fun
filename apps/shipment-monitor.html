总部考核规则

配送指标考核逻辑 · 取值口径：TMS 运输执行订单管理
发车及时率前一天（D0）分拣完成（复核）的货物，须在 次日 16:00 前发车完成（总部规则为 16:00）。
运抵及时率一鸣 & 很忙拉齐口径：分子 = 当日时效内到店运抵完成的订单数量；分母 = 当日时效内应完成履约到店的订单总数量。备注：强配单、自提单、新店剔除考核，均不计入及时率判断。很忙规则：运抵时间 ≤ 应履约日（D0+1）19:00，计为运抵及时，否则超时；一鸣规则：运抵时间 ≤ 应履约日（D0+1）21:00，计为运抵及时，否则超时。
签收率分子 = 当日时效内签收完成的订单数量；分母 = 当日时效内应签收完成的订单数量。备注：强配单、自提单、新店剔除考核，均不计入及时率判断。规则：很忙门店（编码 1 开头）应履约日（D0+1）19:00 前签收；一鸣门店（编码 2 开头）应履约日（D0+1）21:00 前签收。延后宽限：若很忙门店（编码 1 开头）在应履约日 17:00 前运抵，该订单可延迟至 23:00 前完成签收，记为正常签收；若一鸣门店（编码 2 开头）在应履约日 19:00 前运抵，该订单可延迟至 23:00 前完成签收，记为正常签收。
需求车辆数状态属于生效且未发车、未调度的订单，按其总件数合计 ÷ 650 件/车（每台车可装载 650 件）折算，向上取整；已调度 / 已发车 / 在途 / 已运抵 / 已签收及取消类状态订单不计入。
统计口径D0 = 复核时间日期；及时率 = 达标 ÷（达标 + 已超时），未到考核节点的订单计入「进行中」单列，不拉低及时率；强配单 / 自提单 / 新店订单不计入运抵与签收及时率；数据为 TMS 真实导出，无模拟值。

使用说明 · 数据上传字段要求

供其他同事上传 TMS 导出文件时对照 · 字段缺失将导不出或数据不全

一、上传的 Excel 必须包含的字段（列标题含以下关键字即可，顺序不限）

硬字段 · 缺一则整行跳过
  • 调度单号 — 主键，空值整行不计入
  • 复核时间 — 作为 D0，须为日期/时间格式，否则整行跳过
关键字段 · 决定核心指标
  • 承运商简称 — 含「(xx仓)」自动识别仓库
  • 状态 — 在途 / 已运抵 / 已签收 等
  • 收货人 — 门店名
  • 收货人编码 — 1开头=很忙，2开头=一鸣
  • 总件数 — 件数进度与需求车辆
  • 实际出发时间 / 实际到达时间 / 签收时间
  • 是否带板运输 — 带板占比
可选字段 · 缺失则对应功能为空
  • 运输执行订单（或含「订单号」非调度列）— TO 筛选
  • 是否自提 / 是否新店 — 剔除考核
  • 是否剩货 / 剩货件数(一鸣)
  • 封签状态(已封签) / 司机到仓时间 / 司机姓名 / 司机手机号 / 车牌号
  • 到店考核(一鸣)
  • 含强配/强制列且值为「是」→ 强配单剔除
